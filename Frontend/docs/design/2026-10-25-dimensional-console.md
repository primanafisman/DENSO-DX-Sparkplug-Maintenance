# Dimensional operator console

The operator supplied a replacement transparent DENSO/Crafting the Core logo and two light red/white dashboard references. They request a proportional, readable, elegant futuristic style with icons and depth, a server-based seconds clock, Indonesian errors, tool-specific shift completion, and ordinary history containing the X/R test dataset without an example-mode button.

## Approach

Continue the existing React/TypeScript Feature MVC application. Use CSS layers, restrained gradients/shadows and Lucide/SVG icons for dimensional effects; no WebGL, heavy animation library or external fonts. Keep the light palette from the references, semantic OK/NG colours, compact inspection entry, four navigation icons and one page heading. This is the implementer's choice based on the supplied references and existing operator/tablet constraints. The supplied logo is copied verbatim with its aspect ratio and transparency preserved.

The design extends the authorized inline implementation workflow; no new platform, hosting, or approval flow is introduced. Existing confirmation, standards acknowledgement, manual input, evidence and audit boundaries remain.

## Functional boundaries

- Header clock anchors to server time, advances locally each second and periodically resynchronizes; it never drives operational shift decisions or requests the API every second.
- Machine single-value checks remain pending until all eligible linked tools have been checked for the selected line/occurrence. Product subgroups and before/after measurements retain distinct evidence guards.
- Reconcile exact orphan/retry confirmations; scope eligible machine evidence to the operational occurrence instead of blocking the same source forever. Changed values and already completed tool measurements remain guarded.
- Remove example-mode controls and frontend data branches. A development-only CLI imports seven production dates of tagged X/R test data into ordinary local storage. Never fabricate photos or field measurements; preserve visible provenance and separate test product cohorts. Imported examples never complete actual due checks.
- Ordinary reports retain the three cell modes, stable inspection numbers, numeric values and pressure OK/NG charts.

## Validation

Command-only tests cover clock sync, Indonesian error messages, tool/shift evidence scope and due states, trusted import/idempotency/rollback/provenance, normal history routing, and actual values. Responsive CSS supports touch controls, reduced motion and print. Physical monitor/tablet visual acceptance is separate from DOM testing.
